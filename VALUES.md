# Values at Flos Blog

My blog aims to provide valuable information around software Architecture, Azure cloud and all other dev related topics I care about.  

1. **Value over Spam**: We want to create posts and information that is valuable to our readers. It is not about creating a lot of content that is watched by as many people as possible. It is about creating content that helps people to understand what Azure and Architecture is really about.
2. **Content is hand written**: Since AI allows us to produce a lot of content quickly, but at the cost of bad quality and pointless text, creating text is not about writing a lot of text. It is about create a plan what it write, following a clear structure and making a point. To do so, the hearth of each text must be written by hand. Only the review might be supported by AI.
