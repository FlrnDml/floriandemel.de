# Values at Flos Blog

My blog aims to provide valuable information about software development.

1. **Value over Spam**: I want to create posts and information that is valuable to my readers. It is not about creating a lot of content that is watched by as many people as possible. It is about creating content that helps people to understand how software works.
2. **My Topics**: While I want to journal about all kind of software related topics in my posts, my main knowledge is Process, Architecture and Azure.
3. **Understanding over hype**: There are many areas of software that are under discussion, currently it is mostly AI. While I like to be up-to-date, I only write about things I truely understand. Understanding means, I tried it, I saw it or I worked on it. But I dont replicate knowledge from other sources.
4. **Content is hand written**: Since AI allows us to produce a lot of content quickly, but at the cost of bad quality and pointless text, creating text is not about writing a lot of text. It is about create a plan what it write, following a clear structure and making a point. To do so, the hearth of each text must be written by hand. Only the review might be supported by AI.
